NIGHTROUTE - SERVICE NUMBER TRACKING UPDATE

WHAT CHANGED
- Track Service now looks up saved service numbers case-insensitively.
- Matching services display origin, destination, coach/operator label, route variant,
  road distance, estimated average journey time and the saved road geometry on a map.
- Saved services retain a compact route shape so the service can be looked up after
  a page refresh on the same browser/device. The compact service registry retains up
  to 30 recent services to limit browser storage usage.
- Route stop/waypoint details and the existing 7-day replay UI are shown for a matched
  service.
- Added passenger rating and review submission. Reviews are saved locally per service
  on the current browser and an average is calculated from those local reviews.

IMPORTANT DATA LIMITATIONS
- Service numbers, operator labels, schedules and fares generated by this demo are
  illustrative, not verified operator inventory. A service number from a real bus
  operator will not resolve unless that exact number exists in this browser's saved
  NightRoute service registry or bundled sample data.
- The displayed travel time is an OSRM road-routing estimate for the searched path;
  it is not a measured historical average from completed trips.
- The map shows the road geometry retrieved from OpenStreetMap/OSRM. Different
  route variants appear only if the routing engine returns distinct alternatives.
- Previous-week replay remains a simulated playback of the saved route. Genuine
  historical/live bus tracking requires authorized operator AVL/GPS data.
- Passenger reviews are local demo reviews, not public verified ratings. They do not
  sync between devices or represent real operator/customer feedback.

HOW TO USE
1. Start the app and search an origin/destination.
2. Note one generated service number from a result card.
3. Open Track Service and enter that exact service number.
4. Review the route map, estimated journey time, route variant, stops and replay.
5. Add a rating/review; it is stored in this browser for that service.

TRACKING LOOKUP SCOPE
The browser stores up to 30 recent compact service records. Clearing browser site data,
using another browser/device, or searching enough new services can remove an older
service from local lookup. A production deployment should store services and reviews
in the backend database and connect authorized operator feeds.
